# SENSE AI

Prototipe awal asisten pribadi Android untuk Xiaomi Pad 6 / Android 14.

## Fitur prototipe
- Antarmuka gelap biru.
- Input teks dan pengenalan suara (id-ID).
- Text-to-Speech Bahasa Indonesia.
- Daftar pengingat lokal sementara (belum alarm terjadwal).
- GitHub Actions untuk membangun APK debug.

## Build
GitHub Actions akan berjalan saat ada push ke `main` atau dapat dijalankan manual melalui tab **Actions**.
Hasil APK tersedia sebagai artifact bernama `sense-ai-debug-apk`.

## Catatan
Versi ini belum terhubung ke OpenAI API dan belum menjadwalkan notifikasi reminder. Keduanya akan ditambahkan pada iterasi berikutnya. Jangan memasukkan API key ke source code atau repository publik.
